# بازارنما

سایت ایستا روی GitHub Pages.

## به‌روزرسانی داده‌ها
GitHub Actions تقریباً هر ۱۰ دقیقه `update_prices.py` را اجرا می‌کند. صف Actions و کش CDN می‌توانند تأخیر ایجاد کنند؛ اجرای دقیق ۱۰ دقیقه‌ای تضمین نیست.

## سیاست قیمت مستقیم
- قیمت‌های بازار ایران فقط از quote مستقیم یا تجمیع‌شدهٔ ارائه‌دهنده پذیرفته می‌شوند؛ نرخ مشتق‌شده از دلار و قیمت جهانی حذف می‌شود.
- NerkhAra منبع اصلی است. NerkhSanj فقط برای کنترل اختلاف استفاده می‌شود و هرگز قیمت منتشرشده را جایگزین نمی‌کند؛ مستندات عمومی آن می‌گوید بعضی ارقام می‌توانند برآورد مبتنی بر نرخ ارز باشند و تفکیک روش هر نماد در خروجی موجود نیست.
- ارزهای تکمیلی فقط در صورتی وارد مبدل می‌شوند که NerkhAra برای آن‌ها quote مستقیم منتشر کند؛ در غیر این صورت ناموجود می‌مانند.
- واحد ریال/تومان فقط بر اساس برچسب صریح واحد نرمال می‌شود؛ هیچ ضریب حدسی بر اساس نسبت قیمت‌ها اعمال نمی‌شود.
- CoinGecko پشتیبان قیمت جهانی رمزارزها به USD است؛ قیمت USD به‌عنوان USDT یا تومان معرفی نمی‌شود.
- EIA از مسیر CSV عمومی FRED برای برنت فیزیکی، WTI فیزیکی و گاز طبیعی Henry Hub استفاده می‌شود. این سری‌ها روزانه و مرجع‌اند، نه لحظه‌ای.

## API عمومی
- آخرین نرخ‌ها: `/api/v1/latest.json`
- فهرست endpointها: `/api/v1/index.json`
- تاریخچه هر دارایی: `/api/v1/history/{asset_id}.json`
- سلامت منابع: `/api/v1/source-health.json`

تاریخچهٔ کامل در `data/history-archive.json` نگه‌داری می‌شود؛ فایل سبک `data/history.json` برای نمودارهای سایت استفاده می‌شود.
