راهنمای بخش خبرهای اقتصادی بازارنما

این بسته شامل فایل‌های سایت به‌همراه این موارد جدید است:
- scripts/update_news.py: دریافت تیترهای اقتصادی از RSS منابع خبری
- .github/workflows/update-news.yml: اجرای خودکار هر ۱۰ دقیقه با GitHub Actions
- data/news.json: فایل داده‌ای که GitHub Actions به‌روزرسانی می‌کند

منابع در نسخه فعلی:
ایران اینترنشنال، ایسنا، مهر، تسنیم، باشگاه خبرنگاران جوان، تابناک و خبرآنلاین.

نکته مهم:
GitHub Pages به‌تنهایی امکان اجرای زمان‌بندی‌شده سمت سرور ندارد. به همین دلیل این نسخه از GitHub Actions استفاده می‌کند. پس از بارگذاری همه فایل‌ها و پوشه‌ها در ریشه مخزن، در GitHub وارد زبانه Actions شوید، گردش‌کار Update economic news را باز کنید و یک‌بار Run workflow را اجرا کنید. سپس باید در Settings > Actions > General، دسترسی Workflow permissions روی Read and write permissions باشد تا گردش‌کار بتواند data/news.json را به‌روزرسانی و commit کند.

زمان‌بندی هر ۱۰ دقیقه تنظیم شده است؛ اجرای cron در GitHub ممکن است گاهی با کمی تأخیر انجام شود و تضمین دقیق ثانیه‌ای نیست. خود صفحه نیز هر ۱۰ دقیقه فایل منتشرشده را دوباره می‌خواند.

فقط تیتر، نام منبع، تاریخ انتشار و پیوند خبر نمایش داده می‌شود؛ برای متن کامل، کاربر به وب‌سایت ناشر می‌رود. خبرها با کلیدواژه‌های اقتصادی فیلتر و موارد تکراری تا حد امکان حذف می‌شوند.

اگر همه RSSها در یک اجرا در دسترس نباشند، فایل خبر قبلی حفظ می‌شود. این محیط ساخت به اینترنت دسترسی نداشت؛ بنابراین دریافت زنده RSS در اینجا آزمایش نشد. اجرای واقعی دریافت خبر باید در GitHub Actions انجام شود.
