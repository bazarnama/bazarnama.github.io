مستندات API نسخهٔ ۱

API عمومی، ایستا و بدون کلید. نمونه‌های این صفحه از فایل‌های واقعی API ساخته شده‌اند.

نقاط دسترسی

مسیرتوضیح
GET /api/v1/latest.jsonآخرین قیمت‌ها (43 قلم؛ coin: 5، crypto: 13، currency: 11، energy: 6، gold: 3، metal: 5)
GET /api/v1/history/{asset_id}.jsonتاریخچهٔ قیمت؛ فهرست شناسه‌ها در index.json (43 دارایی)
GET /api/v1/index.jsonفهرست دارایی‌ها و الگوی مسیر تاریخچه
GET /api/v1/source-health.jsonسلامت منابع، سقف تازگی و تعداد هر وضعیت

پایهٔ آدرس: https://bazarnama.github.io. فایل‌ها ایستا هستند و با GitHub Actions بازسازی می‌شوند؛ زمان واقعی به‌روزرسانی را از freshness بخوانید، نه از زمان درخواست.

فیلدها

فیلدمعنی
idشناسهٔ دارایی؛ همان نام فایل تاریخچه.
familyگروه: currency، gold، coin، metal، crypto، energy.
name.fa / name.enنام دارایی.
unitواحد قیمت، مثلاً IRT (تومان)، USD، USDT. قیمت‌ها را بدون توجه به این فیلد با هم جمع یا مقایسه نکنید.
priceقیمت فعلی در واحد unit.
change_pctدرصد تغییر ۲۴ساعته؛ ممکن است null باشد.
staleاگر true باشد قیمت زنده تلقی نشود.
updated_utcزمان به‌روزرسانی ثبت‌شده توسط منبع.
freshness.statusوضعیت تازگی: fresh، aging، stale، unknown.
freshness.observed_utcزمان اعلام قیمت توسط منبع.
freshness.checked_utcزمان بررسی توسط بازارنما.
freshness.age_seconds / max_age_secondsسن داده و سقف مجاز آن گروه.
freshness.clock_basisمبنای ساعت: provider_timestamp یعنی ساعت خود منبع؛ unknown یعنی زمان معتبر موجود نبود.
source_name / secondary_sourceمنبع اصلی و (در صورت وجود) منبع مقایسه‌کننده.
source_discrepancy_pctاختلاف درصدی با منبع دوم؛ فقط وقتی منبع دوم دارد.
validation.status / validation.reasonنتیجهٔ اعتبارسنجی بازارنما (جدول دلایل پایین‌تر).
validation_warning / discrepancy_warningهشدار اعتبارسنجی یا اختلاف بیش از آستانه.
sources, method, spread_pct, as_of, price_irtارائه‌شده توسط منبع داده؛ معنی دقیق به مستندات آن منبع بستگی دارد و بازارنما آن‌ها را بازتعریف نمی‌کند. ممکن است نباشند.
page, history (داخل هر قلم)توجه: این آدرس‌ها به وب‌سایت منبع داده اشاره می‌کنند، نه بازارنما. تاریخچهٔ بازارنما فقط از الگوی history_pattern در index.json خوانده شود.

timestamp یعنی Unix UTC بر حسب ثانیه و price در همان unit سطح بالای فایل است. فاصلهٔ نقاط یکنواخت نیست (سال‌های قدیم معمولاً روزانه‌اند و نقاط اخیر می‌توانند ساعتی باشند) و ممکن است شکاف داشته باشد؛ نقطهٔ گمشده را درون‌یابی نکنید.

اعتبارسنجی

دلایل ممکن برای validation.reason (از آخرین اجرا):

دلیلمعنی
ok_in_rangewithin the 24h band
ok_no_baselinenot enough own history for a 24h band; basic checks passed
ok_confirmed_moveoutside the 24h band but confirmed by two consecutive readings
held_outside_24h_rangeoutside the 24h band; waiting for a confirming reading
held_source_conflictindependent sources disagree strongly; waiting for a confirming reading
invalid_numberprice is missing, not a number, not finite or not positive
skipped_staleitem already flagged stale; not re-validated

نمونهٔ اجرا

# curl
curl -s https://bazarnama.github.io/api/v1/latest.json | jq '.items[] | select(.id=="usd") | {price, unit, freshness: .freshness.status}'

# JavaScript
const r = await fetch("https://bazarnama.github.io/api/v1/latest.json");
const { items } = await r.json();
const x = items.find(i => i.id === "usd");
if (x.stale || x.freshness.status !== "fresh") console.warn("not live");

# Python
import requests
d = requests.get("https://bazarnama.github.io/api/v1/history/usd.json", timeout=15).json()
print(d["unit"], d["points"][-1])

سیاست پایداری

  • مسیرها و نام فیلدهای v1 حذف یا تغییر نمی‌کنند؛ فقط فیلد اضافه می‌شود. کد شما باید فیلدهای ناشناخته را نادیده بگیرد.
  • تغییر ناسازگار فقط در مسیر /api/v2/ منتشر می‌شود.
  • بدون کلید و بدون محدودیت رسمی؛ بیش از یک خواندن در دقیقه برای هر فایل لازم نیست. بدون SLA.
  • داده «لحظه‌ای» تضمین‌شده نیست؛ فقط freshness.status = fresh به‌معنی تازه بودن طبق سیاست بالاست و قیمت stale نباید زنده تلقی شود.
  • مجوز بازنشر داده‌های منبع هنوز با تأیید انسانی بررسی نشده؛ پیش از استفادهٔ تجاری آن را بررسی کنید.
