# مقایسه زیرساخت (فاز ۳) — فقط پیشنهاد؛ مهاجرتی انجام نشده

## وضعیت فعلی
GitHub Pages + GitHub Actions. هزینه صفر. محدودیت‌ها: زمان‌بندی تقریبی و بدون تضمین، افزایش حجم git با هر commit، امکان تنظیم نکردن سربرگ‌های HTTP (CSP، Cache-Control)، نبود هشدار سمت سرور و حساب کاربری.

| گزینه | مزایا | معایب | هزینه (تقریبی؛ نرخ‌ها را بررسی کنید) | زمان مهاجرت |
|---|---|---|---|---|
| A) ماندن روی Pages + اصلاحات فاز ۲ | بدون ریسک، بدون قطعی | سقف‌های بالا باقی می‌مانند | صفر | انجام شد |
| B) دامنه اختصاصی + Cloudflare جلوی سایت (Pages هم‌چنان میزبان) | CDN، قوانین کش، سربرگ امنیتی، Rate Limit | نیاز به دامنه؛ روی `bazarnama.github.io` ممکن نیست | هزینه دامنه + پلن رایگان | ۱–۲ روز |
| C) Cloudflare Pages/Workers + KV/D1 برای API و دریافت داده | API زنده، دریافت هر چند دقیقه، هشدار سمت سرور ممکن | کد API باید بازنویسی شود | پلن رایگان تا حدی؛ بعد پولی | ۱–۲ هفته |
| D) VPS + PostgreSQL + Redis | کنترل کامل، تاریخچه ساخت‌یافته | نگهداری، امنیت و پشتیبان‌گیری با خود شما | ماهانه ثابت | ۳–۶ هفته |

## توصیه
اول B (اگر دامنه دارید یا می‌خرید)، سپس C فقط وقتی هشدار سمت سرور یا حساب کاربری واقعاً لازم شد. PostgreSQL/Redis (گزینه D) برای حجم فعلی (۴۵ دارایی، حدود ۱.۴MB تاریخچه) توجیه ندارد.
شرط مهاجرت: URLها و `/api/v1/*` بدون تغییر، و اجرای موازی قدیم/جدید تا اطمینان. **اجرا فقط پس از تأیید شما.**
