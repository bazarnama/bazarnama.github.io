# بازارنما

سایت ایستا روی GitHub Pages.

## به‌روزرسانی داده‌ها
GitHub Actions در `.github/workflows/update-prices.yml` تقریباً هر ۱۰ دقیقه `update_prices.py` را اجرا می‌کند. اسکریپت نرخ‌ها، تاریخچه و فایل‌های API را در مخزن ذخیره می‌کند.

## API عمومی
- آخرین نرخ‌ها: `/api/v1/latest.json`
- فهرست endpointها: `/api/v1/index.json`
- تاریخچه هر دارایی: `/api/v1/history/{asset_id}.json`

تاریخچهٔ کامل در `data/history-archive.json` نگه‌داری می‌شود (حذف نمی‌شود؛ فقط نقطه‌های قدیمی‌تر از 14 روز به یک نقطه در روز فشرده می‌شوند). فایل `data/history.json` نسخهٔ سبک همان تاریخچه است (8 روز اخیر دارایی‌های صفحهٔ اصلی) و سایت فقط آن را می‌خواند. نرخ‌های ارز بازار آزاد از منبع اصلی و یک منبع مستقل مستقیم کنترل می‌شوند؛ نرخ مشتق‌شده از دلار برای یورو، پوند و درهم نمایش داده نمی‌شود.

## منابع نرخ ارز بازار آزاد
- یورو، پوند و درهم از نرخ مستقیم بازار آزاد گرفته می‌شوند؛ نرخ‌های مشتق‌شده از دلار حذف می‌شوند. Iran Market Data منبع مستقل جایگزین است و NerkhSanj صرفاً برای اعتبارسنجی و هشدار اختلاف استفاده می‌شود؛ اختلاف بیش از 5 درصد ثبت می‌شود.
- نرخ ارزهای مشتق‌شده از دلار (مثل ین یا روپیه) دیگر در `data/prices.json` و `api/v1/latest.json` منتشر نمی‌شوند. نرخ‌های جهانی خام در `fx_usd` هست.
- اگر هیچ منبع مستقیمی در دسترس نباشد، به‌جای عدد تقریبی، قیمت نمایش داده نمی‌شود.

## انرژی
- در نبود نرخ تازهٔ منبع اصلی، ترتیب جایگزین برای نفت و گاز شامل Stooq، EIA (در صورت تنظیم کلید) و FRED عمومی است. داده‌های FRED روزانه‌اند و به‌عنوان قیمت لحظه‌ای معرفی نمی‌شوند.

## گردش‌کارها
- `update-prices.yml` و `update-news.yml` در یک گروه همزمانی هستند و هنگام push تا 4 بار دوباره تلاش می‌کنند.
- `cleanup-stray-files.yml` را یک بار دستی اجرا کن تا فایل‌های اضافی ریشه حذف شوند.

## کنترل کیفیت داده (ارتقای نوامبر ۲۰۲۶)
- `price_validation.py`: هر قیمت با بازهٔ ۲۴ ساعتهٔ تاریخچهٔ خودِ پروژه (با تلرانس هر خانواده) و اختلاف منابع سنجیده می‌شود. قیمت مشکوک تا تأیید دریافت بعدی منتشر نمی‌شود و آخرین قیمت معتبر با `stale` می‌ماند؛ جهش واقعی با دو دریافت هم‌خوان پذیرفته می‌شود. دلیل هر تصمیم در `data/validation-log.json` و وضعیت هر قیمت در فیلد افزایشی `validation` است.
- `tools/validate_site.py`: دروازهٔ انتشار (JSON، ساختار تاریخچه، سایت‌مپ XML، canonical، robots، لینک‌های داخلی، JSON-LD). گردش‌کار قیمت و خبر پیش از commit آن را اجرا می‌کنند و در صورت خطا، داده‌های جدید منتشر نمی‌شود.
- `tools/repair_history.py`: گزارش (و با `--apply` حذف) نقطه‌های جهشی منفرد؛ هر حذف در `data/history-repairs.json` ثبت می‌شود.
- `tools/update_sitemap.py`: `lastmod` فقط وقتی تغییر می‌کند که فایل HTML همان صفحه واقعاً تغییر کرده باشد (هش در `data/page-lastmod.json`).
- اخبار: `news_quality.py` (تطبیق کلمهٔ کامل، دسته‌بندی، حذف تکراری بین رسانه‌ها، پذیرش فقط تاریخ معتبر). فیلدهای قبلی حفظ شده و `category`، `relevance`، `also_reported_by` افزوده شده‌اند.
- `site-checks.yml`: تست‌ها و اعتبارسنجی روی هر push، و به‌روزرسانی lastmod سایت‌مپ روی main.


## تغییرات پایداری آپدیت (۱۳ نوامبر ۲۰۲۶)
- علت توقف آپدیت: `update_prices.py` با تست‌ها و بقیهٔ پروژه ناهماهنگ بود (۱۲ تست رد می‌شد) و workflow قیمت پیش از دریافت، همین تست‌ها را اجرا می‌کرد؛ پس هر اجرا متوقف می‌شد.
- `update_prices.py`: اتصال `price_validation.py`، `screen_point` (فیلتر جهش تاریخچه)، `strip_range_fields`، آستانه‌های تازگی مطابق `DATA-FRESHNESS.md`، نرخ‌آرا همچنان منبع اول ارزها.
- `update-prices.yml`: تست واحد دیگر دروازهٔ دریافت قیمت نیست (در `site-checks.yml` اجرا می‌شود)؛ فقط خروجی داده با `validate_site.py --data` پیش از commit بررسی می‌شود. صفحه‌های `transparency.html` و `api-docs.html` ساعتی بازسازی می‌شوند.
- `sw.js`: فایل‌های `/data/` و `/api/` هرگز از کش مرورگر خوانده نمی‌شوند.
- توجه: `import-bazarnama.yml` پوشهٔ `.github/workflows/` را عمداً کپی نمی‌کند؛ فایل‌های workflow را باید دستی در مخزن جایگزین کنید.
